# Dokumentation

| Dokument | Inhalt | Für wen |
|---|---|---|
| [ARCHITEKTUR.md](ARCHITEKTUR.md) | Architektur, Entscheidungen, Plan, Risiken, Quellen | Entwicklung, Review |
| [folien/projekt.md](folien/projekt.md) | Präsentation: Idee, Design, Technik, Fahrplan | Interessierte, Mitwirkende |
| [folien/handbuch.md](folien/handbuch.md) | Präsentation und Anleitung: Juri benutzen | Nutzerinnen und Nutzer |
| [folien/KONVENTION.md](folien/KONVENTION.md) | Regeln für die Folien-Dateien und Prompt für die Umwandlung in PowerPoint | alle, die Folien erzeugen oder pflegen |
| [bilder/](bilder/) | Screenshots für Doku und Folien (ab M2 automatisch erzeugt) | |
| `adr/` | Architecture Decision Records (ab M0) | Entwicklung |

**Folien erzeugen:** Eine Datei aus `folien/` zusammen mit dem Prompt aus [folien/KONVENTION.md](folien/KONVENTION.md) an eine KI geben. Jede `#`-Überschrift wird zur Kapitelfolie, jede `##`-Überschrift zur Inhaltsfolie, `Notizen:` zu Sprechernotizen.

**Pflege:** Jeder Meilenstein aktualisiert Architektur, beide Präsentationen und die Screenshots (Teil der Definition of Done).
