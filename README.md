# Juri

Minimalistische Karteikarten-App (PWA) für das juristische Referendariat, für iPhone und iPad. Alle Daten bleiben lokal auf dem Gerät.

Status: Planung. Architektur, offene Fragen und Umsetzungsplan stehen in [docs/ARCHITEKTUR.md](docs/ARCHITEKTUR.md). Die verbindlichen Design-Screens liegen in [design/](design/).
